# Marvin — User Documentation

Public help center and user guide for **Marvin**, the autonomous research agent.

Marvin conducts deep, multi-step research on your behalf — reading the literature, forming hypotheses, designing and running analyses, and returning structured, evidence-backed findings. This repository holds the end-user documentation (how to use Marvin, what it can do, how billing works, etc.).

> ℹ️ This is the **user-facing** docs site. For the Marvin engine / Marvin Cloud source, see [IluvatarLabs/marvin](https://github.com/IluvatarLabs/marvin).
